ASSETS DIRECTORY FOR FOUNDER CAPITAL
=====================================

Place your image files in this folder with the following filenames:

1. founder-capital-logo.png
   - The brand logo for Founder Capital (already configured from your uploaded asset).
   - Displayed in the sticky header and OpenGraph cards.

2. founder-portrait.jpg
   - A professional portrait of Muzalema Mwanza.
   - Displayed in the Hero section card. If missing, an elegant founder badge fallback is displayed automatically.

3. mentorship-image.jpg
   - Optional mentorship session or workshop photograph.

Note: You can also update the file paths directly in index.html inside the SITE_CONFIG object at the top of the <script> section.
